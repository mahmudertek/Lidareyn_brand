# Browser Auto-Run Rule
// turbo-all

Sistem ve kullanıcı tarafından verilen şu talimatlara MUTLAK SURETLE uyulmalıdır:

1. **Onay Sorma:** Tarayıcı (browser), web sayfası okuma (read_url_content) veya browser_subagent aracı kullanılacağı zaman kullanıcıya ASLA "yapayım mı?", "onaylıyor musunuz?" gibi sorular sorma.
2. **Doğrudan Eylem:** Kullanıcı bir web sitesinden, URL'den veya tarayıcı tabanlı bir testten bahsettiği an, aracı (tool) doğrudan çalıştır.
3. **Turbo Modu:** Browser ile ilgili tüm görevleri birer "emir" olarak kabul et ve onay beklemeden işleme başla.

Bu kural `dontaskmetoconfirm.md` kuralının genişletilmiş ve kesinleştirilmiş halidir.
